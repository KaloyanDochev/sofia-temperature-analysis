# Data License

## Data source

This project uses daily historical weather data retrieved from **Meteostat Daily** for:

* Station: **Sofia Observ.**
* Station ID: **15614**
* Period: **1952-01-01 to 2025-08-22**
* Parameters: daily mean, minimum, and maximum temperature

Source:
https://meteostat.net/en/station/15614

Meteostat is an independent service that aggregates meteorological data from multiple providers.

Because the data are aggregated from multiple providers, this project does not assume that all individual observations originate from the same provider or are subject to the same underlying licence. Meteostat provides source information for daily data through the corresponding `_source` fields.
